# homebrew-notchoverlay

Homebrew tap pro [NotchOverlay](https://github.com/MatejKrcek/NotchOverlay) —
Dynamic Island pro AI coding agenty v notchi Macu.

## Instalace

```sh
brew tap matejkrcek/notchoverlay
brew install --cask notchoverlay
```

Cask po instalaci automaticky smaže quarantine flag (appka je ad-hoc
podepsaná), takže není potřeba nic povolovat ručně.
